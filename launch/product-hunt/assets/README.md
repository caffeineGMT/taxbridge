## Asset Creation Tools

### Screenshots
- **macOS:** Cmd+Shift+4 (area) or Cmd+Shift+5 (full screen)
- **Windows:** Win+Shift+S or Snipping Tool
- **Chrome DevTools:** Device toolbar for mobile views
- **Paid:** CleanShot X (https://cleanshot.com)

### Video Recording
- **Screen recording:** Loom, QuickTime (macOS), OBS Studio (free)
- **Editing:** iMovie (free), DaVinci Resolve (free), Adobe Premiere Pro (paid)
- **Captions:** Descript (auto-generates), Kapwing
- **Music:** Epidemic Sound, Artlist, YouTube Audio Library (free)

### Image Editing
- **Design:** Figma (https://figma.com), Canva (https://canva.com)
- **Remove background:** https://remove.bg
- **Compress:** TinyPNG (https://tinypng.com)
- **Annotations:** Skitch, Snagit, Markup (built-in macOS)

## Quality Control Checklist

Before uploading to Product Hunt, verify:

### Logo
- [ ] Exactly 240x240px
- [ ] Transparent background (not white)
- [ ] High resolution (no pixelation)
- [ ] Matches brand colors

### Gallery Images
- [ ] 5-8 images total
- [ ] Correct dimensions (1920x1080px or 1080x1920px for mobile)
- [ ] No personal/sensitive data visible
- [ ] Clear annotations (if using arrows/text)
- [ ] Consistent design style

### Video
- [ ] 60-90 seconds length
- [ ] 1080p resolution
- [ ] Captions included
- [ ] Background music (not too loud)
- [ ] CTA at end (URL + discount code)
- [ ] File size <100 MB

### First Comment
- [ ] 200-400 words
- [ ] Includes founder story
- [ ] Explains value prop clearly
- [ ] Mentions special offer (PRODUCTHUNT50)
- [ ] Ends with a question (drives engagement)
- [ ] Proofread (no typos)
