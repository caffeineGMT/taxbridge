## Technical Specifications

### Architecture
- **Headless RSU Calculations**: Batch processing of 1,000+ vesting events per minute
- **SQLite Multi-Tenant Data Isolation**: Separate database schemas per firm for GDPR/PIPEDA compliance
- **Clerk RBAC**: Role-based access control (Admin, Partner, Paralegal, Read-only)
- **AES-256 Encryption**: At rest and TLS 1.3 in transit

### Compliance & Security
- **SOC 2 Type II** certified (Q3 2026 target)
- **GDPR** and **PIPEDA** (Canada) compliant
- **IRS Publication 54** aligned tax calculations
- **Annual security audits** by third-party firms
- **Data residency**: AWS US-West-2 (Oregon) and Canada regions only
