## Red Flags (Fix Immediately)

🚨 **CPC > $6** → Add negative keywords, pause broad match
🚨 **CTR < 2%** → Rewrite headlines, check ad relevance
🚨 **50+ clicks, 0 conversions** → Landing page issue, check tracking
🚨 **Budget gone by noon** → Lower max CPC, spread bids

**If funnel breaks:**
- Step 1→2 low? → Hero copy not compelling
- Step 2→3 low? → Calculator UX issue
- Step 3→4 low? → CTA not strong enough
- Step 4→5 low? → Pricing issue, nurture sequence needed

## Quick Actions

**Pause underperforming keyword:**
```
Google Ads → Keywords → Select keyword → Status: Paused
```

**Add negative keyword:**
```
Google Ads → Keywords → Negative keywords → Add → "keyword"
```

**Increase bid:**
```
Keywords → Select keyword → Edit max CPC → +$0.50
```

**Check conversion attribution:**
```
PostHog → Insights → Filter utm_source=google → View funnel
```

---

## Budget Optimization

**If CPA < $80** (winning!)
- Increase daily budget by 20%
- Expand to similar keywords
- Test Display remarketing

**If CPA $80-120** (on target)
- Maintain current spend
- Optimize ad copy
- Add more negative keywords

**If CPA > $150** (losing)
- Pause broad match keywords
- Lower max CPC by 10%
- A/B test landing page
- Check conversion tracking working
