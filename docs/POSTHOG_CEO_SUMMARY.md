## What Needs to Happen (15 Minutes)

### 1. Get PostHog Production Key (5 min)

**What**: Login to PostHog dashboard and copy production API key

**Who**: You (requires PostHog account access)

**Steps**:
1. Go to: https://app.posthog.com
2. Login (or create account if needed)
3. Click: Project Settings → Copy "Project API Key"
4. Key format: `phc_` + 43 characters

**Output**: Production API key (example: `phc_AbCdEfGhIjKlMnOpQrStUvWxYz1234567890AbC`)

---

### 2. Update Vercel Environment Variable (5 min)

**What**: Replace placeholder key in Vercel with production key

**Who**: You (requires Vercel dashboard access)

**Steps**:
1. Go to: https://vercel.com/caffeineGMT/taxbridge/settings/environment-variables
2. Find: `NEXT_PUBLIC_POSTHOG_KEY`
3. Click: Edit
4. Replace: `phc_YOUR_PROJECT_API_KEY` with your real key
5. Save → Vercel will auto-redeploy (wait 3 minutes)

**Output**: Production deployment with real PostHog key

---

### 3. Verify It Works (5 min)

**What**: Confirm PostHog is tracking events on production site

**Who**: Engineer (automated script)

**Steps**:
```bash
# Run automated verification
npm run verify:posthog:production
```

**Output**:
- ✅ Production site accessible
- ✅ PostHog loaded on production
- ✅ Network requests detected
- ✅ Events being tracked
- 📸 Screenshots saved to `docs/screenshots/`
- 📄 Verification report generated

**Manual Check**:
1. Visit: https://app.posthog.com/project/YOUR_PROJECT_ID/events
2. Click: Activity → Live Events
3. Should see: Events from taxbridgecpa.com appearing in real-time
