# Verification Evidence Directory

This directory stores verification evidence for task completion, per CLAUDE.md Task Completion Policy.

## Evidence Types

### Screenshots
- **Format**: PNG, JPG
- **Naming**: `{feature}-{status}-{YYYY-MM-DD}.png`
- **Examples**:
  - `sentry-production-active-2026-03-19.png`
  - `stripe-live-payment-success-2026-03-19.png`
  - `posthog-events-tracking-2026-03-19.png`

### Videos
- **Format**: MP4, WebM
- **Max Duration**: 2 minutes
- **Naming**: `{feature}-demo-{YYYY-MM-DD}.mp4`

### Logs
- **Format**: TXT, LOG
- **Naming**: `{feature}-verification-{YYYY-MM-DD}.log`

## Evidence Requirements

Per CLAUDE.md, tasks marked "DONE" must include ONE of:
1. Screenshots (desktop + mobile)
2. Video recording (max 2 min)
3. Logs/terminal output
4. Deployed feature URL (HTTP 200)
5. Analytics data
