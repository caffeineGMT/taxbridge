# TaxBridge Product Hunt Demo Video Script

**Duration:** 60 seconds
**Platform:** Loom (screen + webcam) or QuickTime (screen only)
**Resolution:** 1080p minimum

---

## Recording Setup

### Tools Needed
- **Loom** (recommended): https://loom.com - Free, easy, professional
  - Sign up → Click "Record" → Select "Screen + Cam" or "Screen Only"
  - Use "Full Desktop" or "Current Tab" mode

- **Alternative:** QuickTime (Mac built-in)
  - File → New Screen Recording → Record entire screen or selected portion

### Pre-Recording Checklist
- [ ] Browser window at 1920x1080 resolution (or max available)
- [ ] Clear browser cookies/cache for clean demo
- [ ] Prepare demo data (RSU entries ready to show)
- [ ] Close unnecessary browser tabs
- [ ] Mute notifications (Do Not Disturb mode)
- [ ] Test audio (built-in mic is fine, but test levels)
- [ ] Have script printed or on second monitor

---

## Shot-by-Shot Script

### SHOT 1: Hook & Problem (0:00-0:10)
**Screen:** Landing page (scroll hero section slowly)

**Voiceover:**
> "Are you an H-1B or TN visa tech worker with RSU income now living in Canada? Cross-border taxes are a nightmare. You're getting taxed twice - once in the US and again in Canada."

**Action:**
- Open https://taxbridge.com in browser
- Slow scroll through hero section
- Cursor hover over "Get Started" button (but don't click)

## Pro Tips

✅ **Pace yourself:** Don't rush. 60 seconds is longer than you think.
✅ **Show, don't tell:** Let the UI speak. Point at features with cursor.
✅ **Real data:** Use realistic demo data, not "Test User" or "123 shares"
✅ **Smooth movements:** Move cursor slowly and deliberately
✅ **Smile in your voice:** Even screen-only, enthusiasm is contagious
✅ **One take is fine:** Don't stress perfection. Authenticity > polish

❌ **Avoid:** Dead air, "um"s and "ah"s, rushed speech, shaky cursor
