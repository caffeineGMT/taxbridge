# Verification Reports Directory

This directory stores automated verification reports for task completion.

## Report Types

### Automated Verification Scripts
- **Format**: TXT, LOG, JSON
- **Naming**: `{feature}-verification-{YYYY-MM-DD}.log`
- **Examples**:
  - `sentry-verification-2026-03-19.log`
  - `stripe-verification-2026-03-19.log`
  - `production-health-check-2026-03-19.json`

### Manual Verification Reports
- **Format**: Markdown
- **Naming**: `{feature}-activation-complete-{YYYY-MM-DD}.md`
- **Examples**:
  - `sentry-activation-complete-2026-03-19.md`
  - `clerk-activation-complete-2026-03-19.md`
