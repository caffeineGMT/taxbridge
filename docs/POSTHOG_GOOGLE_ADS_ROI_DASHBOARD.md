# PostHog Google Ads ROI Tracking Dashboard
**Setup Guide for Real-Time Campaign Performance Monitoring**

---

## Overview

This dashboard tracks Google Ads campaign performance in real-time using PostHog custom insights. It provides actionable metrics to optimize spend, identify winning keywords, and measure ROI.

**Key Metrics Tracked:**
- Click-through rate (CTR)
- Cost per click (CPC)
- Cost per acquisition (CPA)
- Customer acquisition cost (CAC)
- Return on ad spend (ROAS)
- Revenue attribution by keyword/campaign

### Insight 3: Cost Per Acquisition (CPA)

**Name:** "Google Ads - CPA by Campaign"
**Type:** Custom Formula

**Formula:**
```
Ad Spend ÷ Email Captures
```

**How to Calculate in PostHog:**

Since PostHog doesn't track ad spend automatically, you'll need to:

1. **Option A: Manual Input (Simple)**
   - Track daily spend manually in Google Ads
   - Create PostHog event: `google_ads_daily_spend`
   - Properties: `{ spend: 16.67, date: "2026-03-19" }`
   - Fire event daily via cron job or manual tracking

2. **Option B: Google Ads API Integration (Advanced)**
   - Use Google Ads API to auto-import daily spend
   - Store in PostHog custom property
   - Calculate CPA automatically

**Manual Calculation:**
- **Email Captures:** Count of `email_verified` WHERE `utm_source=google`
- **Ad Spend:** Sum of `google_ads_daily_spend.spend`
- **CPA:** `Ad Spend ÷ Email Captures`

**Target:** < $100 per email capture

### Insight 5: Return on Ad Spend (ROAS)

**Name:** "Google Ads - ROAS"
**Type:** Custom Formula

**Formula:**
```
Revenue ÷ Ad Spend × 100%
```

**How to Calculate:**
- **Revenue:** Sum of `checkout_completed.revenue` WHERE `utm_source=google`
- **Ad Spend:** Sum of `google_ads_daily_spend.spend`
- **ROAS:** `(Revenue ÷ Ad Spend) × 100%`

**Target:** > 100% (break-even minimum)
**Stretch Goal:** > 300% (3:1 return)

**Example:**
- $500 ad spend → $1,500 revenue = 300% ROAS ✅
- $500 ad spend → $150 revenue = 30% ROAS ❌

---

### Insight 6: Customer Acquisition Cost (CAC)

**Name:** "Google Ads - CAC"
**Type:** Custom Formula

**Formula:**
```
Ad Spend ÷ Paid Customers
```

**How to Calculate:**
- **Paid Customers:** Count of `checkout_completed` WHERE `utm_source=google`
- **Ad Spend:** Sum of `google_ads_daily_spend.spend`
- **CAC:** `Ad Spend ÷ Paid Customers`

**Target:** < $100 (requires $49 pricing + 100% LTV capture in Month 1)
**Realistic:** $200-500 (given 0.135% conversion rate)

**Benchmark:**

- **Financial Software:** $150-300

## Google Ads Spend Tracking (Manual)

Since Google Ads doesn't automatically send spend data to PostHog, you need to track it manually.

### Option 1: Daily Manual Entry (Simple)

**Script:** `scripts/track-google-ads-spend.ts`

```typescript
import { PostHog } from 'posthog-node';

const posthog = new PostHog(
  process.env.NEXT_PUBLIC_POSTHOG_KEY!,
  { host: process.env.NEXT_PUBLIC_POSTHOG_HOST }
);

async function trackDailySpend(spend: number, date: string) {
  posthog.capture({
    distinctId: 'google-ads-system',
    event: 'google_ads_daily_spend',
    properties: {
      spend,
      date,
      currency: 'USD',
    },
  });

  await posthog.shutdown();
  console.log(`✅ Tracked $${spend} spend for ${date}`);
}

// Usage: npm run track-spend -- 16.50 2026-03-19
const spend = parseFloat(process.argv[2]);
const date = process.argv[3] || new Date().toISOString().split('T')[0];

trackDailySpend(spend, date);
```

**Daily Workflow:**
1. Open Google Ads dashboard
2. Check yesterday's spend (e.g., $16.50)
3. Run: `npm run track-spend 16.50 2026-03-19`
4. PostHog dashboard updates automatically

### Option 2: Google Ads API Integration (Advanced)

**Auto-import daily spend via Google Ads API:**

```typescript
// scripts/sync-google-ads-spend.ts
import { GoogleAdsApi } from 'google-ads-api';
import { PostHog } from 'posthog-node';

const client = new GoogleAdsApi({
  client_id: process.env.GOOGLE_ADS_CLIENT_ID,
  client_secret: process.env.GOOGLE_ADS_CLIENT_SECRET,
  developer_token: process.env.GOOGLE_ADS_DEVELOPER_TOKEN,
});

const customer = client.Customer({
  customer_id: process.env.GOOGLE_ADS_CUSTOMER_ID,
  refresh_token: process.env.GOOGLE_ADS_REFRESH_TOKEN,
});

async function syncSpend() {
  const yesterday = new Date();
  yesterday.setDate(yesterday.getDate() - 1);
  const dateStr = yesterday.toISOString().split('T')[0];

  const report = await customer.query(`
    SELECT
      campaign.name,
      metrics.cost_micros,
      metrics.clicks,
      metrics.impressions
    FROM campaign
    WHERE segments.date = '${dateStr}'
  `);

  const posthog = new PostHog(process.env.NEXT_PUBLIC_POSTHOG_KEY!);

  for (const row of report) {
    const spend = row.metrics.cost_micros / 1_000_000; // Convert micros to dollars

    posthog.capture({
      distinctId: 'google-ads-system',
      event: 'google_ads_daily_spend',
      properties: {
        spend,
        date: dateStr,
        campaign: row.campaign.name,
        clicks: row.metrics.clicks,
        impressions: row.metrics.impressions,
      },
    });
  }

  await posthog.shutdown();
  console.log(`✅ Synced Google Ads spend for ${dateStr}`);
}

syncSpend();
```

**Setup:**
1. Enable Google Ads API in Google Cloud Console
2. Get OAuth credentials
3. Install: `npm install google-ads-api`
4. Set env vars in `.env.production`
5. Run daily via cron: `0 9 * * * npm run sync-ads-spend`

## ROI Calculation Examples

### Example 1: Positive ROI Scenario (Target State)

**Inputs:**
- Ad Spend: $500/month
- Clicks: 110 (at $4.55 avg CPC)
- Email Captures: 5 (5% of 110 clicks = 4.5% conversion)
- Paid Customers: 1 (5% of 5 emails, $79 pricing)
- Revenue: $79

**Metrics:**
- CPC: $4.55 ✅
- CPA: $100/email ✅
- CAC: $500/customer ❌
- ROAS: 15.8% ❌
- ROI: **-84.2%** (still negative)

**Conclusion:** Even at target conversion rates and $79 pricing, ROI is negative in Month 1. Requires 3-6 month payback period via retention.

---

### Example 2: Break-Even Scenario

**What would it take to break even in Month 1?**

**Given:**
- Ad Spend: $500
- Pricing: $79/year

**Required:**
- Paid Customers: 6.3 (to generate $500 revenue)
- Email Captures: 126 (at 5% email→paid conversion)
- Clicks: 2,520 (at 5% click→email conversion)
- CPC: $0.20 (to afford 2,520 clicks on $500 budget)

**Reality Check:**
- Industry CPC for finance keywords: $4-15
- Required CPC: $0.20
- **Gap:** 20-75x lower CPC needed

**Conclusion:** Impossible to break even in Month 1 at current conversion rates. Requires either:
1. 20x lower CPC (unrealistic)
2. 20x higher conversion rate (need 100% click→email, not 5%)
3. 20x higher pricing ($1,580/year, not $79)
4. Multi-year LTV calculation (accept negative Month 1, optimize for retention)
