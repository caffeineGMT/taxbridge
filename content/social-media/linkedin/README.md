# LinkedIn Viral Campaign: "I Saved $12K on RSU Taxes"

## Overview

This directory contains all assets for the TaxBridge founder story LinkedIn campaign targeting H-1B/TN tech workers with RSUs.

**Campaign Goal:** Drive 20 email signups through viral LinkedIn post + $100 ad spend

**Target Metrics:**
- 10K impressions
- 200 clicks
- 20 email signups
- CAC < $5

## Quick Start

### If You Have 5 Minutes
1. Read `post-copy-ready-to-publish.txt`
2. Review the post copy
3. Schedule on your calendar: Tuesday 8 AM PST

### If You Have 30 Minutes
1. Read `founder-story-viral-post.md` (full campaign guide)
2. Create visual asset using `visual-asset-spec.md`
3. Draft LinkedIn post (save as draft, don't publish yet)
4. Set up LinkedIn ad campaign (save as draft)

### If You Have 2 Hours
1. Complete all 30-minute tasks above
2. Read `launch-day-script.md` fully
3. Create friend share list (10-15 people)
4. Join 3-5 LinkedIn Groups for posting
5. Set up PostHog tracking events
6. **You're ready to launch!**
